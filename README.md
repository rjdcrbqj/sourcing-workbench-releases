# 选品采购台

用于 Amazon 选品、1688 找货和采购对比的 Chrome 扩展。

- [下载最新安装包](https://github.com/rjdcrbqj/sourcing-workbench-releases/releases/latest/download/sourcing-workbench.zip)
- [查看历史版本](https://github.com/rjdcrbqj/sourcing-workbench-releases/releases)

## 首次安装

下载 Release 附件中的 `sourcing-workbench.zip`，解压到固定目录。在 Chrome 打开 `chrome://extensions/`，开启「开发者模式」，点「加载未打包的扩展程序」，选择包含 `manifest.json` 的目录。

## 覆盖更新

1. 在选品池点「备份 JSON」。
2. 将新版 ZIP 解压并覆盖原安装目录中的文件。
3. 回扩展管理页，在「选品采购台」旁点「重新加载」，核对版本和选品池。使用原浏览器配置和原安装目录。

## 订阅新版

登录 GitHub，在本仓库点击 **Watch → Custom → Releases → Apply**。收到通知后下载新版，按上面的方法更新。
